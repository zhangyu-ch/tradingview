# 期货参数版本（B11）

## 新回测如何选择

```python
config["futures_parameter_version"] = "2024-12-13-r2"
```

- 覆盖允许区间：2024-12-13 起。保证金与手续费仍是旧快照，**不是当前实时标准，也不是按日期切换的真实历史标准**。
- 仅修正四个合约乘数，其他 16 个品种以及手续费/保证金未变：

| 品种 | 旧值 | 修正值 | 单位 |
|---|---:|---:|---|
| CZCE.TA（PTA） | 10 | 5 | 吨/手 |
| DCE.I（铁矿石） | 50 | 100 | 吨/手 |
| DCE.Y（豆油） | 20 | 10 | 吨/手 |
| SHFE.AU（黄金） | 20 | 1000 | 克/手 |

## 早期历史的显式兜底

```python
config["futures_parameter_version"] = "legacy-static-r2"
```

- 复制修正版本的完整参数，允许 1900-01-01 以后的计算区间；`1900` 只是程序边界，**不代表当时已有这些品种或参数真实有效**。
- 选择该版本时会打印 `static approximation` 警告；结果 manifest 中保留版本、来源日期、近似用途及 SHA256。
- 没有默认回退：不填版本仍报错；普通版本越界仍报错；不存在的品种仍报错。
- 适合策略探索，不应将其计算出的绝对收益、资金利用率、手续费作为真实历史交易成本。严谨回测仍需要真实的分时期参数，并让引擎按交易日选择。

## 为什么旧记录还在

`2024-12-13` 原始记录保持字节内容和规范化哈希不变，仅允许校验/读取已有保存结果，不再允许通过 manifest builder 创建新回测。直接修改原记录会使全部已保存结果报 `dataset hash mismatch`，因此发布了新修订号。

- 旧结果可以打开，但不会被悄悄重算，其历史数值仍包含旧乘数的影响。
- 使用旧版本启动新回测会明确提示改用 `2024-12-13-r2` 或 `legacy-static-r2`。
- 想修正旧结果，必须用新版本重跑，而不是修改 pkl 或绕过哈希检查。
- 优化和多进程缓存身份包含参数快照哈希，并在复用前核验完整哈希。旧的无版本缓存保留，但不会自动用于新期货回测；误放到新路径的异版本缓存会明确报错，不覆盖它。普通市场的文件名与复用逻辑保持原样。

## 维护要求

数据文件：`src/tradingview_zy/backtesting/futures_parameters.json`。任何参数变更都发布新版本，不覆盖已有快照；旧版本退役策略位于 `futures_contracts.py`。校验测试固定了原始 dataset/snapshot 哈希，防止后续误改破坏兼容。
